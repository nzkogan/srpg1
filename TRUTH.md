# The truth file

The game refuses to settle its central questions on screen. That only works if the answers exist off screen, so that
every clue, scene and historian's account can be consistent with one truth. This file is for those answers. It is
Nick's to write; nothing here is canon until it is filled in. Keep it out of the game's data.

For each question: what canon already fixes (the constraints), then a space for the answer.

## 1. The missing name

Constraints: in the prologue the scribe Nashar writes the patron of Ur-Nashet into the book and the name is never shown.
In F1 (the scribes' quarter) the First Register is copied and a page is lost; "the missing name enters the world here,
as an accident nobody notices." The overworld already says Ur-Nashet's patron was Belial (drafted by a build session;
confirm or change).
